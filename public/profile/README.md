# Profile avatar

Drop your sidebar profile photo in both folders (same filename in each):

| Theme | Path |
|-------|------|
| Light | `light-mode/avatar.jpg` |
| Dark  | `dark-mode/avatar.jpg`  |

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp` — update paths in `SiteSidebar.tsx` if you use a different extension.
