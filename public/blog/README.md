## Rules

- Use the exact filename from `IMAGES.txt` (including extension).
- `.jpg` / `.jpeg` for photos, `.png` for screenshots — or match the extension in the filename.
- Frame `01` is the cover when a post has a cover image.
- After adding files, refresh the blog page — paths are already wired in `src/app/data/blogs.ts`.
